# Sensor Data Analysis Tool

Mijn eerste Python-opdracht. Het programma maakt nep-metingen van een sensor (of laadt ze uit een CSV-bestand), berekent statistieken met NumPy en maakt twee grafieken met Matplotlib.

Installeren: pip install -r requirements.txt

Starten: python sensor_monitor.py

Kies 1 om nieuwe metingen te maken of 2 om sensor_readings.csv in te laden. De metingen worden opgeslagen in sensor_readings.csv en de grafieken in readings_plot.png en readings_histogram.png.
